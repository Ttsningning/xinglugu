# 星露谷专属手机（xinglugu）

这是面向 SillyTavern 星露谷主题角色卡的独立手机扩展项目，与 xiaowangzi 无关。

## 当前状态
这是独立开发的基础框架，不是 Junimo Pocket 的完整移植版。已建立可开关的悬浮手机外壳，后续逐项实现角色卡专属功能。

## 安装（开发版）
在 SillyTavern 的第三方扩展管理中使用本仓库地址安装，或将仓库放入 `public/scripts/extensions/third-party/xinglugu`。刷新酒馆后，页面右下角出现「星露谷手机」入口。

## 功能规划
- 农场：土地、作物、动物、建筑、技能、任务、日历、地图
- 社交：私聊、群聊、朋友圈、信件、送礼、红包、关系与生日
- 物品：背包、箱子、衣柜、图鉴、图纸、商店、金币与交易
- 剧场：IF 独立进度、主线冻结、奖励结算与档案
- 系统：状态同步、候选回复回退、备份导入导出、跨聊天继承、外观主题、API 预设

## 参考与授权
功能需求参考 [Junimo Pocket](https://github.com/EvelynOvO5/sillytavern-junimo-pocket) 的公开说明。此仓库目前不包含其源代码、美术或其他受保护素材；在取得明确许可前不整仓复制。新代码独立编写。

## 开发原则
优先保障 SillyTavern 兼容性、状态一致性、交易幂等、回退安全和备份可恢复性。不要将开发框架误认为已经实现上述全部功能。
